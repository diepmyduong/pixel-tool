# Composite an Items Collage instead of dropping items past the 3-image API limit

The video generation API accepts at most 3 reference images per request. With Character and Reference Image now both optional-but-combinable, and Items able to be multi-selected, the naive `[character?, referenceImage?, ...items]` list can exceed 3 entries. We decided to always reserve one slot for a composed **Items Collage** (a grid image combining all selected items when there are 2+, or the raw blob when there's exactly 1) rather than silently truncating extra items or rejecting the request. This keeps every selected item visually represented in the generation input regardless of how many are picked, at the cost of each individual item being smaller/lower-fidelity in the collage than it would be as a standalone reference.
